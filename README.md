# 基层健身项目补贴成效对账与拨付复核

本项目围绕社区全民健身公共服务的本地分析资料。数据均为合成记录，文件字段与时间口径按各自数据文件表示。项目目录包含业务资料、分析软件包和基础数据检查。

## 环境与运行

需要 Python 3.11 或更新版本，无第三方运行依赖。进入项目目录后运行 `python -m unittest discover -s tests -v` 检查合成资料。分析包位于 `src/grants`，可从 Python 导入。输入资料位于 `data/`，CSV 使用 UTF-8 编码和首行字段名，策略资料采用 JSON。

生成复核报告：

```
PYTHONPATH=src python -m grants --data data --out report.json
# 带迟到更正单（可选）
PYTHONPATH=src python -m grants --data data --corrections corrections.csv --out report.json
```

## 数据约定

所有居民、机构、地点与活动均为虚构标识，时间以数据字段的本地日期表示。空字段表示该资料没有登记值，不应据此推断业务事实；具体数据口径以相应字段和 JSON 政策文件为准。资料用于离线分析，不含外部服务或凭据。

`data/policy.json` 是唯一的策略事实来源，约定：观察日与回看周期、金额精度与舍入层级、
成效档阈值与报销费率、居民组名册、已有服务居民名册、其他来源资助、同事件份额合计上限、
当前账版本。`data/corrections.csv` 为可选更正单；未提供时视为本月无更正。

## 复核口径（src/grants）

- **覆盖与成效（coverage.py）**：覆盖人数以合同约定居民组和回看周期为准，已有服务与
  新增覆盖分开统计；同一居民在合同内、共担项目和全区口径都只计一次，人头与加权成效都
  不随签到次数翻倍，跨合同达标判断按合同 `share_weight` 计入加权成效。
- **共同支出（costs.py）**：可报销额 = 金额 × 获批份额；同事件各合同份额合计超过
  `share_sum_limit`（默认 1.0）即判超分，该事件费用全部先排除；未获批、无合资格签到
  支撑的费用同样逐条进入阻塞清单，不进入可支付金额，新合资格费用不得掩盖未处理重叠。
- **拨付测算（disbursements.py）**：可拨余额由合资格费用、成效档（未达最低档本轮为 0）、
  合同额度、已生效其他来源资助共同决定。已送达确认的批次只扣减、绝不重写；超拨差额只在
  同一合同尚未送出的建议内抵扣，余额生成人工追缴，不跨合同、不挪用途；未送出批次按本轮
  事实重算并保留原账版本，额度不足部分才出新增建议。
- **更正单（coverage.apply_corrections）**：观察日之前已生效的更正改写签到居民；迟到或
  未生效的更正不改事实，只登记阻塞。更正合并居民可能拉低成效档并导致补贴超拨，超拨按
  上一条处理。
- **精度（money.py）**：金额内部用 `Decimal`，逐条按未舍入值累计，仅在聚合层按策略精度
  统一 ROUND_HALF_UP；舍入残差随报告披露，不因按合同独立舍入凭空产生可拨余额。
- **可复核性**：报告内所有视图共用同一观察日；每条阻塞记录给出原因代码与事实说明，
  每条拨付建议附事实备注（含锁定批次的账版本、更正单编号），可追溯"为什么不能拨、
  差额由哪次事实更正造成、当时批准的是哪一版账"。

## 测试资料

`tests/fixtures/late_correction/` 是一套迟到更正情景：包含已生效合并更正、迟到未生效
更正、份额超分事件、未获批费用、居民组未证实与窗口外签到、已送达与未送出批次、其他来源
资助和合同额度封顶，用于端到端验证上述口径。
